# SleepWell Beds - Каталог мебели

Интернет-витрина с каталогом кроватей, фильтрацией по стилям, корзиной и модальным окном для просмотра деталей товара.

## Описание

Проект представляет собой одностраничное приложение (SPA) на React, демонстрирующее каталог мебели с возможностью:

- Просмотра товаров в виде карточек
- Фильтрации по категориям (стилям)
- Добавления товаров в корзину
- Просмотра детальной информации в модальном окне
- Управления корзиной (удаление товаров)

## Технологии

- **React** (классовые и функциональные компоненты)
- **CSS3** (стили, анимации)
- **React Icons** (иконки)
